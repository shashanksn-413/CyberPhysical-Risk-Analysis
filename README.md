# Cyber-Physical Risk and Resilience Analysis of National Water Infrastructure

## Overview
This project analyzes the cyber and physical resilience of a regional water infrastructure network using cascade network modeling, directed flow analysis, and Model-Based Risk Analysis (MBRA).

The study models a 10-state infrastructure system to evaluate how cyber intrusions, infrastructure failures, and physical disruptions propagate across interconnected systems. The project combines network science, critical infrastructure analysis, and cybersecurity risk assessment to identify critical nodes, evaluate resilience, and measure system-wide risk reduction strategies.

---

## Objectives
- Model cyber and physical infrastructure dependencies using graph theory
- Perform cascade and directed flow network analysis
- Calculate centrality, eigenvalues, and spectral characteristics
- Identify critical infrastructure nodes and links
- Evaluate resilience under random and targeted attacks
- Analyze cyber-physical propagation behavior
- Apply MBRA for risk and resilience evaluation

## Key Analysis Performed
- Cascade network analysis
- Directed flow network analysis

- Eigenvector centrality analysis
- Spectral radius evaluation
- Random attack simulation
- Targeted attack simulation
- Fault tree analysis
- Risk reduction analysis

---

## Key Findings
- Identified critical infrastructure nodes with highest systemic impact
- Demonstrated how lack of redundancy enables cascading failures
- Evaluated resilience differences between cyber and physical propagation models
- Applied targeted mitigation strategies that significantly reduced overall system risk
